How it works

One handshake through us. Everything else peer to peer.

OpenInvestorPortal is a registry and a certificate authority. It introduces investor and portal to each other exactly once. Every request, every document and every statement afterwards travels directly between the two peers, and we are not in the path.

01 · Register

Investor creates a key

A keypair is generated on the investor's device. Only the public key is registered with OpenInvestorPortal and becomes the investor's identity. The private key never leaves.

02 · Link

Portal links the account

Inside the portal's own UI the investor clicks “Connect with OpenInvestorPortal”. The portal stores the public key against the account and we issue a signed link certificate. No password is shared with anyone.

03 · Peer to peer

Direct, signed, offline-verifiable

The investor's client signs each request with its key and calls the portal's endpoint directly. The portal checks the signature and the link certificate offline, with no call to us. Reports, capital calls and documents flow peer to peer. Revocation propagates in under an hour.

The protocol Coming soon

OIPP: a small surface every portal can implement

Read-only REST, mirrored as MCP tools. Payloads follow the ILPA templates. Requests are signed with HTTP Message Signatures (RFC 9421) and carry a short-lived link certificate signed by us, so portals verify everything offline.

# investor client → portal, directly
GET /oipp/v1/capital-calls?since=2026-01-01
Authorization: OIPP oip:inv_7f3a
OIPP-Link: eyJhbGciOi…   # signed by OpenInvestorPortal, 24h
Signature-Input: sig=("@method" "@target-uri" "content-digest")
Signature: sig=:MEUCIQ…:   # signed by the investor's key

# portal verifies, returns ILPA-shaped JSON
200 OK
{ "capital_calls": [ { "fund": "…", "due_date": "2026-02-15",
    "amount": { "value": 250000, "currency": "EUR" } } ] }
# resources every OIPP portal exposes
GET /oipp/.well-known/oipp          # discovery, JWKS
GET /oipp/v1/accounts               # commitments on this portal
GET /oipp/v1/documents              # metadata, filters
GET /oipp/v1/documents/{id}/content
GET /oipp/v1/capital-calls          # ILPA capital call template
GET /oipp/v1/distributions          # ILPA distribution template
GET /oipp/v1/capital-account-statements
GET /oipp/v1/notifications?cursor=  # change feed
